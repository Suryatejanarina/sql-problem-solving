# sql-problem-solving
SQL practice problems solved with joins, CTEs, window functions, and aggregations (MySQL)

## Overview
This repository contains my solutions to 35+ SQL interview-style problems.
Each problem includes the table setup, sample data, and the solution query,
so every query can be run as it is. The queries are written in MySQL.

## Topics Covered
- Joins and self-joins
- Common Table Expressions (CTEs)
- Window functions: `RANK`, `ROW_NUMBER`, `LAG`, `LEAD`
- Aggregations with `GROUP BY` and `HAVING`
- Conditional logic with `CASE WHEN`
- Date functions (`DATE_ADD`, `DATEDIFF`)
- Set operations (`UNION`)
- String aggregation (`GROUP_CONCAT`)

## Problems Include
- New vs repeat customers
- Cancellation rate of ride requests
- Customer retention and churn
- Daily and weekly active users
- Consecutive empty seats and consecutive increasing values
- Second most recent activity per user
- Prime subscription conversion rate
- Products frequently purchased together
- Missing quarters per store
- Match results and points table (ICC World Cup)
- Winner in each group

## Project Structure
- `sql-problem-solving.sql`: all problems and solutions

## How to Use
1. Download `sql-problem-solving.sql`.
2. Open it in MySQL Workbench or any MySQL client.
3. Run each problem's section to create the table, insert the data, and view the result.
